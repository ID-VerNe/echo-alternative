# 克拉克森风格编译管线 · 实验报告（v1 → v4）

结论先行：**这条管线可行，但不是靠"把风格写成规则"跑通的。** 在 12 个与语料无关的问题上，v4 版管线对"单条人设 Prompt"的基线，双向盲评 6 胜 1 负 5 分歧，独立绝对评分 8 胜 3 负 1 平（均分 32.1 vs 30.3，满分 50）。

真正起作用的是三件事：草稿层只交"人尺度事实"、spec 里把喜剧密度写成硬指标、以及用 rubric 评判器在 3 个候选里挑最优。反过来，v2 和 v3 两次试图"收敛、限流、让它理性一点"，盲评是 0:4 和 0:6——越正确越不像。

但第七节会说明，这个胜利里有很大一块是"人工诊断 + 两轮改写"的功劳：同样一套流程换成 James May、全自动编译，就只能和一句人设 Prompt 打平（3:3:6），加了预算约束重编还输得更惨（0:8:4）。这条管线的目标场景不是复刻名人，而是模型没见过的作者。

第九节是最后、也是最有用的一步：把整件事交给一个干净上下文的 agent 之后，它的**初稿**就以 7:0:5 赢了一句人设、以 3:1:8 摸平我们的管线；而它自己"对照规则逐条返修"出来的定稿，反而打不过自己的初稿（4:0:8）。结论因此变成：**资产 + 会看风格的裁判 + 多候选，比"规则自查循环"更接近答案。**

## 一、语料与离线资产

- 44 本 markdown（正文约 30MB），清洗去重后 **5,930 段 / 189 万词**。
- 克拉克森本人 23 本（农场系列、世界系列），同域负样本 10 本（James May 等）。
- 风格锚点 **234 条**：按问句密度、hedge/hype/insult 词、短句占比打分，再按表达功能四分（rant / argument / anecdote / selfmock）跨书均衡采样。
- 硬统计（纯代码，不经模型）：句长中位数 14 词、30% 句子 ≤8 词、13% ≥30 词；不用分号/括号/感叹号/双引号。

## 二、在线管线（v4）

```
问题 → 意图分类（规则优先）
     → 草稿节点：只出事实清单（£ 价格、时刻、地点、一个物理细节；禁瓦数/型号/实验室）
     → 3 个候选：闹剧类比线 / 场景+自拆台线 / 假条例线
     → rubric 评判器（6 轴 1–5 打分）挑最优
     → 输出
```

每题约 7 次模型调用（1 草稿 + 3 生成 + 3 评判）。在 `coarena/gpt-6-luna` 上，3 并发下 60–90 秒/题。

|---|---|---|
| diction 用词 | 7.08 | 6.75 |
| rhythm 节奏 | 6.83 | 6.50 |
| **comedy 喜剧引擎** | **7.08** | **6.25** |

## 四、四次翻车与修正

1. **Cosine Delta 在 150 词量级上失效**。通用 AI 的 Δref 只有 0.80–0.89，比克拉克森本人段落（0.92）还"像"他——因为短文本的虚词分布会趋近语料均值，它度量的是"典型性"不是"作者身份"。已降级为辅助指标，不单独做门禁。
2. **语域泄漏**。v1/v2 的草稿节点用中立分析师口吻产出瓦数、型号、美元，风格节点又忠实保留事实，成品是"带克拉克森节奏的美国消费电子测评"。修法：草稿节点只给"人尺度事实"，并禁瓦数/型号/实验室。
3. **装置清单化**。v1 每段都塞三段式荒诞清单 + 4–6 连问，像在逐条执行 spec。修法：约束"同一装置不得重复使用"，并让 rubric 评判器惩罚堆叠。
4. **过度收敛**。v2/v3 把装置限流之后，文本变得正确、理性、无趣，盲评直接 0:4 和 0:6。这是最重要的一条：**风格的主体是幽默密度，不是句长和标点。**

## 五、评测方法上的两个坑

- **位置偏差很强**。pairwise 盲评中，管线排在 A 位时 11/12 被判更像，排在 B 位时只有 6/12。所以只认"双向一致"的结果，单方向 pair 不可信。
- **同源裁判**。评判器与生成器是同一个模型，存在自偏好。绝对评分只能缓解位置偏差，不能证明它就是人的判断。

## 六、还差什么

- **人工金标准**：抽 100 条人工排序，验证 rubric 与人的相关性，这是把指标变成门禁的前提。
- **第二裁判 / 跨家族模型**：排除同源偏好。
- **换作者复测**：现在的基线之所以强，是因为强模型"本来就知道"克拉克森。管线相对人设 Prompt 的真正价值区，是模型没见过的私域作者——那才是应该拿来做主实验的场景。
- **标点习惯**：punct_cos 0.422 仍低于基线 0.524，破折号、省略号、逗号问句这些"手感"还没学到位。
- **成本**：3 候选 + 3 评判可以压缩成 2 候选 + 规则预筛，或把 rubric 的偏好蒸馏成 DPO 对，长期替代采样。

## 七、迁移性检验：同一套流程，换成 James May

用同一套离线流程（清洗 → 锚点 → spec 自动归纳）和同一套在线流程（1 草稿 + 3 候选 + 参照式 rubric rerank），把作者换成 James May：6 本书、740 段、21 万词、55 条锚点（约为克拉克森语料的九分之一）。

| 方案 | Δref ↓ | Δmargin ↑ | kNN ↑ | 句长JS ↓ | 标点cos ↑ | 盲评 胜/负/分歧 |
|---|---|---|---|---|---|---|
| May 自动编译 spec | 0.952 | +0.097 | −0.053 | 0.151 | 0.434 | 3/3/6（n=12） |
| May 加"预算约束"重编（222 词，无百分比） | 0.979 | +0.041 | +0.004 | 0.109 | 0.609 | 0/8/4（n=12） |
| May 人设 Prompt 基线（对应两行） | 0.949 / 0.934 | +0.103 / +0.133 | +0.027 / +0.027 | 0.132 / 0.131 | 0.488 / 0.490 | — |

结论不太好听，但很有用：

1. **一次性自动编译，打不过一句人设 Prompt**（3:3:6 平，指标略输）。加预算约束把 1,400 字符的百分比表压到 222 词，机械指标更漂亮了（标点 0.434→0.609、句长 0.151→0.109），盲评反而 0:8 崩掉——又一次证明机械指标和"像不像"是两回事。
2. **克拉克森的胜利有过拟合成分**。v4 的两条关键修订（喜剧密度、人尺度事实）是我先看输出、诊断、再手写进 spec 的。那不是"编译"的功劳，是"人的诊断 + 两轮改写"的功劳。May 没有这两轮，就现了原形。
3. **强模型本来就认识这些名人**。基线的强，来自参数里已有的克拉克森/May；管线要证明自己，必须去模型不认识的地方。所以"复刻名人"不是这条管线的目标场景，**私域作者 / 小语种 / 未出版稿件**才是。

自动编译暴露的通用缺陷（已修成代码，见 `experiments/e15_compile.py`）：归纳会把直方图百分比原样抄进 prompt（"17.22 词""32.2% ≤8 词""9.47% ≥36 词"），模型于是去凑数字。给编译器的固定预算约束是"200–260 词、最多三个数字、不许抄百分比表"。但这只治了形式，没治"空"——真正的修法是把人的诊断做成搜索循环：**归纳 spec → 用 rubric 在留出段落上打分 → 让模型针对失分轴改写 spec → 再评**，直到留出集不再涨。这是下一步要做的实验。

## 八、把"人的诊断"交给 agent（E16–E18）

目标：不需要我在旁边看输出、写规则，让 agent 自己读语料、自己诊断、自己改资产。

协议（全程无人工）：段落级留出 20%（hash 分桶），锚点与 spec 只用训练桶；每条留出段落先用"事实提取器"压成中性 brief（只留立场、论点、具体细节），再用当前 spec 重写成段，用五轴 rubric 对照原段落打分；agent 读最差 4 条 + 各轴得分，输出新的 compiled_prompt；复评，保留历史最优。

留出均分曲线：**23.3 → 23.9 → 22.8**。第 2 轮退步——它把"照抄原段落的结构和顺序"写成了规则，节奏被带偏。这一轮暴露了循环设计的两个必备件：保留最优、早停。

第 1 轮诊断原文（这条意见本身很值钱）：

> The weakest axis is restraint: the generated passages repeatedly add polished metaphors and interpretive commentary that the targets don't need. The prompt's fixed argument pattern also turns varied material — directions, factual anecdotes, comic asides — into the same tidy essay, flattening its voice and movement.

但盲评不认。在没参与过调优的 10 条留出段落上：**调优版 0 胜 / 未调优 5 胜 / 5 分歧**。rubric 涨了，人味掉了——和第七节、和 v1→v4 的教训一模一样：**可数的轴会把人往"忠实复述"拉，而裁判看重的是节奏、俏皮、自嘲。**

于是做第二轮，把裁判判词直接喂给 agent："你的 rubric 涨了、裁判更不喜欢了，找原因。"它的诊断更尖锐：

> The prompt's opening and structure rules encouraged clean thesis-first exposition, while its sentence-length targets and demand for substantial paragraphs made the prose feel engineered. Its caution against invented judgments and polished jokes suppressed the source's conversational asides, dry evaluations, and concrete scene-by-scene movement.

改完在另一批 10 条留出段落上验收：**2 胜 / 2 负 / 6 分歧**——从"明显更差"回到"打平"（注意 A 位胜率 8/10，位置偏差依旧，严格一致的样本只有 4 条）。

三条结论：

1. **装置可用**：agent 能读、能诊断、能改，诊断质量接近人类编辑，而且改的是机制（开头怎么起、论点怎么转、结尾落在哪），不是往 prompt 里堆形容词。
2. **一轮改写不足以翻盘**：21 万词语料、每轮 10 条留出，信噪比太低；rubric 目标还会主动误导。同样的循环换到克拉克森身上之所以 6:1:5，是因为语料大 9 倍、且有人做了两轮针对性修订。
3. **正确的循环长这样**：judge-in-the-loop（用盲评胜率当奖励，而不是五轴分）+ best-of-N spec 搜索（一次生成 5–8 个变体，而不是改一次）+ 30–50 条留出样本。这三件加起来，才是"agent 自己把资产调到能打"的配置。

关于"微调 LM"：现在做到的是 **prompt 级蒸馏**（把书的规则压进 compiled_prompt 与锚点库）。真正的权重微调（LoRA / DPO）需要训练侧，这个推理接口做不到；但上面的循环可以把胜/负样本对攒下来，正是将来做 DPO 的训练集。

## 九、把整件事交给 agent（E19–E20）

两个版本，区别只在"谁来写"。

**E19：干净上下文 agent，调外部接口写。** 12 篇、平均 3.9 轮（3–5 轮），每篇逐条对照 spec 自查再改。

| 对比（双向一致才算） | 胜 | 负 | 分歧 |
|---|---|---|---|
| agent 定稿 vs 管线（best-of-3） | 7 | 1 | 4 |
| agent 定稿 vs 一句人设 | 10 | 0 | 2 |
| agent 初稿 vs 定稿 | **初稿 5** | **定稿 0** | 7 |
| agent 初稿 vs 管线 | 7 | 0 | 5 |

**E20：agent 自己写，完全不调外部接口。** 12 篇、平均 4.75 轮，六路并行，每路只读资产、互不可见；定稿 211–246 词、3 段、禁用项零命中。

| 对比 | 胜 | 负 | 分歧 | A 位胜率 |
|---|---|---|---|---|
| agent 定稿 vs 管线 | 3 | 2 | 7 | 10/12 |
| agent 定稿 vs 一句人设 | 7 | 0 | 5 | 12/12 |
| agent **初稿** vs agent **定稿** | **4** | **0** | 8 | 12/12 |
| agent 初稿 vs 管线 | 3 | 1 | 8 | 11/12 |

机械指标（E20，同一批文本）：self_final Δref 1.006 / margin −0.011 / punct 0.606；pipeline 0.938 / +0.123 / 0.415；baseline 0.919 / +0.161 / 0.521。**Δref 最差的文本，被裁判判为最像这位作者**——这已经是第四次机械指标与裁判背离。

四条结论：

1. **真正的增益来自"一个会写、肯给具体细节、敢自嘲的 agent"，不来自"自查返修循环"。** 两个版本里，agent 的初稿就已经赢了管线和人设；定稿反而退步。E19 的初稿 vs 定稿 5:0，E20 的 4:0，方向完全一致。
2. **自查为什么减分，有账可查**：E19 记录 104 条违反项，55% 是句长/节奏、11% 是分号这类可数项；把违规逐条修干净，等于把散文压向合规——词数从 283 压到 236，中位句长从 18.1 降到 12.3，标点种类被删（punct 0.495→0.606 是变好，但 JS 变差）。E20 的 agent 也承认："迭代主要不是让文章更好笑，而是让初稿里已经好笑的东西不被规则压掉。"
3. **裁判比指标可信，但裁判有强位置偏差**：E20 的 A 位胜率 10–12/12。只有双向一致能算数，可一旦这么算，每组只剩 4–8 条判决，n=12 不够定案。
4. **产品形态因此变清楚**：资产（spec + 锚点）+ N 个候选 + 会看风格的裁判选优，而不是"一条草稿 + 规则返修"。评审器必须是裁判，不是计数器；而且要做位置随机化、双裁判、30–50 题。

一个诚实的限定：E20 的"一个 agent"实际是六路并行写作者，各自只看资产、互不可见——相当于六个独立写手，而不是一个连续自我修正的 agent。这个差异会影响"迭代"的解释，但不影响"初稿优于返修稿"的结论。
