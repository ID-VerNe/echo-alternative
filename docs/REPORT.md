# 克拉克森风格编译管线 · 实验报告（v1 → v4）

结论先行：**这条管线可行，但不是靠"把风格写成规则"跑通的。** 在 12 个与语料无关的问题上，v4 版管线对"单条人设 Prompt"的基线，双向盲评 6 胜 1 负 5 分歧，独立绝对评分 8 胜 3 负 1 平（均分 32.1 vs 30.3，满分 50）。

真正起作用的是三件事：草稿层只交"人尺度事实"、spec 里把喜剧密度写成硬指标、以及用 rubric 评判器在 3 个候选里挑最优。反过来，v2 和 v3 两次试图"收敛、限流、让它理性一点"，盲评是 0:4 和 0:6——越正确越不像。

## 一、语料与离线资产

- 44 本 markdown（正文约 30MB），清洗去重后 **5,930 段 / 189 万词**。
- 克拉克森本人 23 本（农场系列、世界系列），同域负样本 10 本（James May 等）。
- 风格锚点 **234 条**：按问句密度、hedge/hype/insult 词、短句占比打分，再按表达功能四分（rant / argument / anecdote / selfmock）跨书均衡采样。
- 硬统计（纯代码，不经模型）：句长中位数 14 词、30% 句子 ≤8 词、13% ≥30 词；不用分号/括号/感叹号/双引号。

## 二、在线管线（v4）

```
问题 → 意图分类（规则优先）
     → 草稿节点：只出事实清单（£ 价格、时刻、地点、一个物理细节；禁瓦数/型号/实验室）
     → 3 个候选：闹剧类比线 / 场景+自拆台线 / 假条例线
     → rubric 评判器（6 轴 1–5 打分）挑最优
     → 输出
```

每题约 7 次模型调用（1 草稿 + 3 生成 + 3 评判）。在 `coarena/gpt-6-luna` 上，3 并发下 60–90 秒/题。

## 四、四次翻车与修正

1. **Cosine Delta 在 150 词量级上失效**。通用 AI 的 Δref 只有 0.80–0.89，比克拉克森本人段落（0.92）还"像"他——因为短文本的虚词分布会趋近语料均值，它度量的是"典型性"不是"作者身份"。已降级为辅助指标，不单独做门禁。
2. **语域泄漏**。v1/v2 的草稿节点用中立分析师口吻产出瓦数、型号、美元，风格节点又忠实保留事实，成品是"带克拉克森节奏的美国消费电子测评"。修法：草稿节点只给"人尺度事实"，并禁瓦数/型号/实验室。
3. **装置清单化**。v1 每段都塞三段式荒诞清单 + 4–6 连问，像在逐条执行 spec。修法：约束"同一装置不得重复使用"，并让 rubric 评判器惩罚堆叠。
4. **过度收敛**。v2/v3 把装置限流之后，文本变得正确、理性、无趣，盲评直接 0:4 和 0:6。这是最重要的一条：**风格的主体是幽默密度，不是句长和标点。**

## 五、评测方法上的两个坑

- **位置偏差很强**。pairwise 盲评中，管线排在 A 位时 11/12 被判更像，排在 B 位时只有 6/12。所以只认"双向一致"的结果，单方向 pair 不可信。
- **同源裁判**。评判器与生成器是同一个模型，存在自偏好。绝对评分只能缓解位置偏差，不能证明它就是人的判断。

## 六、还差什么

- **人工金标准**：抽 100 条人工排序，验证 rubric 与人的相关性，这是把指标变成门禁的前提。
- **第二裁判 / 跨家族模型**：排除同源偏好。
- **换作者复测**：现在的基线之所以强，是因为强模型"本来就知道"克拉克森。管线相对人设 Prompt 的真正价值区，是模型没见过的私域作者——那才是应该拿来做主实验的场景。
- **标点习惯**：punct_cos 0.422 仍低于基线 0.524，破折号、省略号、逗号问句这些"手感"还没学到位。
- **成本**：3 候选 + 3 评判可以压缩成 2 候选 + 规则预筛，或把 rubric 的偏好蒸馏成 DPO 对，长期替代采样。
